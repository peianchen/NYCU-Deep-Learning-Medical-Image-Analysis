# 公開資料與隱私邊界

[課程首頁](../README.md)

## 公開與排除項目

公開內容限於本人提交 Notebook 的去識別整理副本、分析文件、已審查的彙整圖表，以及有來源與授權標示的偵測 helpers。

不公開 DICOM、NIfTI、MRI／SPECT／超音波／X 光像素、標註圖、個案 mask、病患 ID／年齡／性別資料列、預測 CSV、COCO 個案 JSON、CAM 疊圖、模型權重、資料集壓縮檔、課程講義、題目全文、其他同學答案與原 Word／PDF 報告。

即使是已編號的資料、已做熱力圖的影像或只顯示部分身體，仍不因外觀處理就自動取得公開授權。原資料維持在本機，不會為了讓 GitHub 圖片更豐富而上傳。

## Notebook 去識別處理

1. 移除全部 outputs、execution_count、附件與不必要 metadata。
2. 檔名改成作業功能名稱，替換學號與示範用病患字串。
3. 只保留原 Markdown 的短標題；移除輸入資料展示、完整課程指令與競賽邀請連結。
4. 將 shell／magic setup 行註解，避免無意安裝、下載或 clone；外部依賴改於文件說明。
5. W&B entity 改成 placeholder；公開版不包含 API key 或登入資訊。

訓練程式保留原演算法與已知問題，沒有在去識別時暗中修正模型。所有匯入檔都有前後 SHA-256；公開來源索引使用角色 alias，不曝光原學號檔名。本機 `.local/` 的原始路徑對照與候選圖片不納入 Git。

## 圖片審查

66 個候選圖經 contact-sheet 視覺審查，選出 37 張統計、學習曲線、參數或程式截圖。醫學影像、原始輸入 montage、個案代碼與 CSV 截圖均排除。重複出現在 Word 與 Notebook 的曲線通常只留一份。

圖表不等於匿名化資料集；本 repository 沒有授予任何原課程資料的使用或再散布權。若未來新增影像或模型，需重新確認授權、去識別及公開必要性。

## 臨床界線

本專案沒有前瞻性試驗、外部多中心驗證、臨床安全性或法規符合性評估。Accuracy、Dice、AP 或 CAM 視覺效果只描述課程實驗，不能直接證明實際診斷能力或醫師一致性。
